# Agent Server and ResponsesAgent Contract

## Server registration

The current Agent Server pattern is:

```python
from mlflow.genai.agent_server import AgentServer, invoke
from mlflow.types.responses import ResponsesAgentRequest, ResponsesAgentResponse


@invoke()
async def run(request: ResponsesAgentRequest) -> ResponsesAgentResponse:
    return build_response(request)


server = AgentServer("ResponsesAgent")
app = server.app
```

Import the module containing `@invoke()` before running the app. Use `@stream()` only with a
validated `ResponsesAgentStreamEvent` implementation and a client that consumes the documented
stream. `AgentServer.run(app_import_string=...)` is the useful path when multiple workers need
an importable application.

## Request/response tests

Cover:

- one user message and multi-turn input;
- assistant messages and tool-call/tool-output items;
- malformed or missing `input`;
- custom output and final response items;
- streaming event ordering, cancellation, and a final event;
- provider timeout/error and tool authorization failure;
- trace/session/version metadata for both success and failure.

`ResponsesAgent` is a PyFunc-compatible structured agent interface. It is designed for tools,
multiple output messages, multi-turn conversations, custom outputs, token tracking, and OpenAI
Responses API compatibility. Preserve the schema metadata and input example generated by the
installed MLflow version; do not hand-edit them to an arbitrary chat-completions shape.

## Packaging boundary

Models from Code is often safer for framework agents with dynamic or unpickleable state. The
source file is executed during logging/loading, so it must not create indexes, mutate external
systems, or fetch secrets at import time. Declare dependencies/resources and test loading in a
clean environment.

## Evaluation boundary

Use `get_invoke_function()` to evaluate the registered callable without requiring an HTTP hop.
Wrap the request in `ResponsesAgentRequest`, return `ResponsesAgentResponse`, and use a fixed
dataset. Add trace-aware scorers for tool/retriever behavior and deterministic code checks for
schema/authorization invariants.
