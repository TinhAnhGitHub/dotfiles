# Python design-pattern references

Start with [`index.md`](index.md). Pages are organized by design pressure rather than by a book's
chapter order. Each pattern page explains when to use it, why it helps, what problem it solves,
when not to use it, trade-offs, tests, and its own embedded framework examples.

Concrete adapted snippets live directly on the relevant pattern page under `## Framework examples`.
The framework matrix is only a crosswalk for requested AI/ML ecosystems. Source provenance is
recorded in [`sources.json`](sources.json); [`arjancodes-2026-map.md`](provenance/arjancodes-2026-map.md)
audits the complete ArjanCodes 2026 tree; `fluent-python-map.md` records the relationship to the
older clean-code material.
