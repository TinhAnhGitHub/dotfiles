# Fluent Python provenance map

The clean-code skill formerly exposed material by Fluent Python chapter. It is now linked by
problem and pattern family:

| Source material | Pattern-first destination |
|---|---|
| First-class functions and closures | Functional boundaries, Strategy, Command, Registry, Decorator |
| Type hints and protocols | Typed boundaries, Dependency Injection, Adapter |
| Pythonic objects and special methods | Value objects, Composite, Iterator, Delegation |
| Iterators and generators | Iterator, Lazy Evaluation, Pipeline |
| Context managers and concurrency | Lifecycle, Resource Ownership, Async Boundaries |
| Properties, descriptors, and metaprogramming | Python-specific implementation patterns |

The chapter structure is provenance, not primary navigation.
