chapter mappings, and evidence levels are maintained in each linked dossier. Every
source/test cell below names concrete repository-relative paths from the linked

Evidence is deliberately not inferred from names or README claims: A = direct implementation plus runtime/test evidence; B = verified implementation with indirect or integration tests; C = inferred or incomplete and not authoritative.
