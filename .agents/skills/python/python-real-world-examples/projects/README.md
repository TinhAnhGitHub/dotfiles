# Open-Source Case Studies

This directory contains in-depth architectural dissections of production open-source Python projects demonstrating Clean Code, Design Patterns, and Clean Software Architecture.

See [`../templates/project-case-study.md`](../templates/project-case-study.md) for the case-study format.


## Corpus and evidence policy

The 45 dossiers in this directory correspond to the pinned revisions in
[the source manifest](../../python-software-architecture/references/source-manifest.json).
Use the [repository matrix](../../python-software-architecture/references/repository-pattern-matrix.md)
to find a pattern across projects.

Each dossier records source and test paths, book mappings, evidence level, Python
versus native ownership, production compromises, and a practice exercise. The
retained OpenViking, CowAgent, Agent-Reach, Graphify, and Canonical AI Frameworks
dossiers are historical case studies and remain valid alongside the pinned corpus.
